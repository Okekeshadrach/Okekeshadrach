# Okeke Ifechidere Shadrach

Full-stack engineer building AI-powered products and production web applications.

I work end to end: data model and API, interface, deployment. Most of what I build ships for real
businesses — hospitality, real estate, payments and retail — so I care about the parts that keep a
product running: permissions, audit trails, payment safety and clean handover documentation.

**Infra** Docker · Docker Compose · Coolify · GitHub Actions

## Selected work

**[MyGPT — AI employee platform](https://github.com/Okekeshadrach/mygpt-ai-employee)**
A universal AI employee platform: a per-business "brain", persistent customer memory, an agent
pipeline shared by every channel, and a permission model that keeps owners in control of what the AI
may do alone. Real-estate vertical pack as the reference implementation.
`Next.js 14 · TypeScript · Express · Socket.IO · Docker`

**[YourSub — subscription & bill payments](https://github.com/Okekeshadrach/yoursub-website)**
Wallet-funded platform for airtime, data, cable TV and electricity, with multi-provider routing,
idempotent purchases, automatic refunds and a Filament admin panel.
`Laravel · Filament · Paystack · Flutterwave`

**[Mart — e-commerce storefront + admin](https://github.com/Okekeshadrach/mart)**
Storefront and separate API/admin service covering catalogue, cart, orders and site settings.
`Laravel · Filament · Sanctum`

Some of my recent client work (hospitality booking platforms, a field survey app) is in private
repositories. Happy to walk through it on request.
